# Step 51 — إزالة تخزين الأرقام السرية كنص صريح

## الهدف
منع تسريب الأرقام السرية (PIN) للمعلمين ومسؤولي الحاسب ومديري المراحل عبر قراءة IndexedDB أو كود/بيانات النظام.

## التغييرات
1. **لا يُحفظ `pin` كنص صريح** — فقط `pinHash`.
2. **عرض مرة واحدة + طباعة فورية من الذاكرة** عند التوليد/إعادة التوليد.
3. **`stripPlaintextPins`** عند تحميل وحفظ قاعدة البيانات الرئيسية.
4. **إنشاء حسابات مسؤول الحاسب ومدير المرحلة** محصور برئيس الكنترول.
5. **التغيير الذاتي** لرقمهم مسموح بعد التحقق من الرقم الحالي + قوة عالية + عرض مرة واحدة.
6. طباعة جماعية/لاحقة بدون رقم مولَّد للتو تعرض تنبيهاً واضحاً (يجب إعادة التوليد).
7. تصدير Excel للمعلمين بدون عمود الرقم السري.
8. `buildRootSecure` ينظّف أي `pin` قبل الرفع للسحابة.

## الملفات الرئيسية
- `js/core/storage.js` — stripPlaintextPins + استدعاؤها عند التحميل/الحفظ
- `js/auth/session.js` — formatPinOnceHtml محسّن
- `js/app/teachers.js` — إنشاء/إعادة توليد/طباعة/تصدير/استيراد
- `js/app/student-roster.part01.js` — التغيير الذاتي
- `js/app/student-roster.part02.js` — مديرو المرحلة
- `js/app/student-roster.part03.js` — مسؤولو الحاسب + طباعة البطاقات
- `js/features/cloud-sync.js` — تنظيف قبل المزامنة
- `docs/SECURITY.md` — توثيق السياسة الجديدة

## ملاحظات تشغيلية
- بعد التحديث، أي أرقام كانت مخزّنة كنص صريح تُحذف تلقائياً عند أول تحميل؛ الدخول يعتمد على `pinHash` كما هو.
- لإعادة طباعة بطاقة: ولّد رقماً جديداً واطبع فوراً.
