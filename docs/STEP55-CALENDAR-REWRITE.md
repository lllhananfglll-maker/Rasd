# STEP 55 — إعادة كتابة الروزنامة

## الملفات
- `js/domain/calendar/term-calendar.js` — منطق نقي
- `js/features/calendar/calendar-bridge.js` — تخزين + تعميم المراحل
- `js/features/calendar/calendar-ui.js` — واجهة التحرير
- `js/app/school-info.js` — ربط الحفظ/التحميل

## كيف تحفظ الفترات؟
1. بيانات المدرسة → الروزنامة المركزية
2. عدّل الفترات (اسم / من أسبوع / إلى أسبوع / اختبار شهر)
3. اضغط **حفظ الروزنامة**
4. أو عدّل «ضبط فترات الرصد» ثم **حفظ بيانات المدرسة والفترات**

## التحقق
1. أضف 3–4 فترات بأسماء واضحة → حفظ الروزنامة
2. سجّل خروجاً ثم دخولاً
3. يجب أن تظهر نفس الأسماء والنطاقات
4. بدّل المرحلة — نفس الفترات
